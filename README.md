# Hey, I am Raffael

I live in Basel and work as an AI architect. By day I am Enterprise Solution Architect for AI Platforms and
Agentic AI at [Helvetia Baloise Group](https://www.helvetiabaloise.com/), helping define a Group-wide platform
for the secure, governed use of foundation models, agents, and AI-assisted engineering.

The rest of the time I build things. For years my ideas lived in a notebook because there was never enough time
to try them. AI changed that: the bottleneck moved from writing the code to deciding what is worth building. So now
I try a lot of ideas, ship them in small and real form, and see which ones stick. Some become serious projects.
Some stay fun. Both are fine.

It all lives under [raskell.io](https://www.raskell.io) (raskell = rascal × Haskell × Raffael, tanuki mascot
included). Tech that serves humans. Boring by default, precise when required.

## The threads

Most of what I build falls into three threads. The same habits run through all of them: open standards,
sane defaults, and systems that keep working when reality shows up.

### Secure edge infrastructure

Where I have spent most of my career: reverse proxies, WAFs, and the traffic in between.

- [**Zentinel**](https://zentinelproxy.io) ([GitHub](https://github.com/zentinelproxy/zentinel)): a security-first reverse proxy on Cloudflare Pingora, with isolated security agents, SDKs in 7 languages, a pure Rust ModSecurity engine, and a fleet control plane. My most-used project.
- [**Sango**](https://sango.raskell.io) ([GitHub](https://github.com/raskell-io/sango)): edge diagnostics in one command: TLS, HTTP/3, security headers, latency.
- [**Vela**](https://github.com/raskell-io/vela): no-downtime app deployment on bare metal. One binary, no containers. It runs my own apps in production.

### Languages and tooling

Compilers, package managers, frameworks, and specs. The tools I wish existed.

- [**Arcanist.sh**](https://arcanist.sh): Haskell tooling built in Rust. [**hx**](https://hx.arcanist.sh) is a fast package and project manager; [**bhc**](https://bhc.arcanist.sh) is an alternative compiler with runtime profiles and tensor-native numerics.
- [**Refrakt**](https://refrakt.raskell.io) ([GitHub](https://github.com/raskell-io/refrakt)): a convention-first web framework for Gleam.
- [**WASM-AD**](https://wasmad.raskell.io) ([GitHub](https://github.com/raskell-io/wasm-ad)): a fantasy console standard whose cartridges are WebAssembly modules, with a spec, reference renderer, and SDK.
- [**seijaku**](https://github.com/raskell-io/seijaku): 静寂 the zero-JavaScript Zola theme behind raskell.io.

### Local-first apps and games

Small things you can open right now. Your data stays on your device; the games run in the browser.

- [**Kurumi**](https://kurumi.raskell.io): a local-first, AI-native second brain that works offline.
- [**Manabi**](https://manabi.raskell.io): 学 a reading-first language-learning app for Chinese, Japanese, and Hebrew.
- [**Paw & Claw**](https://pawandclaw.raskell.io): turn-based tactics in the spirit of Advance Wars, fought by woodland armies.
- [**Rainbow River**](https://rainbowriver.raskell.io): a handheld-era fishing game, and the first WASM-AD cartridge.
- [**Terrarium**](https://terrarium.raskell.io): a simulation where LLM-powered agents form emergent societies.
- [**broodwar.live**](https://broodwar.live): the community platform for StarCraft: Brood War, with replay analysis in the browser.
